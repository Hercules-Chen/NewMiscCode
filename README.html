01-mcp-ui-verifier

  • MCP Server（stdio）提供 14 個工具：open_page、click、fill、assert_text、check_console_errors、screenshot_annotate、generate_report、run_scenario 等。
  • CLI：node src/cli.js demo 會啟動內建含故意錯誤的示範頁，跑完產出報告。
  • 選項：--lang zh-TW|en、--headed、--devtools、--debug、--trace、--cdp-port。
  • 輸出預設：%ProgramData%\NewMiscCode\01-mcp-ui-verifier。
  • 範例報告：examples/report.html
  • Windows 首次執行請跑 setup.bat（npm install + npx playwright install chromium）。

02-local-semantic-search

  • 模型：Xenova/multilingual-e5-small（int8 ONNX，384 維），以 node scripts/fetch-model.js 下載（預設 HuggingFace，會驗 SHA-256），不進 git。
  • 索引：index --dry-run 先預覽，再正式寫入；依檔案雜湊增量更新。
  • 排序：FTS5 BM25（中文雙字切詞）+ sqlite-vec KNN，以 RRF 融合。
  • 離線備援：--embedder hash（字元 n-gram，無語意能力）。
  • 資料/Log 預設：%ProgramData%\NewMiscCode\02-local-semantic-search。
  • 注意：雲端開發環境擋 HuggingFace，當時是從第三方 npm 套件 dsh-plugin-discover-model 取得同一模型檔（已驗 SHA-256）。正式使用請改用 HuggingFace 官方來源。

03-duckdb-wasm-dashboard

  • npm install && npm run build 會把 wasm（每個 30MB 以上，不進 git）複製到 public/vendor。
  • start-windows.bat 啟動本機伺服器並開瀏覽器；網址加 ?debug=1 開啟除錯輸出，?lang=en 切英文。
  • dist/artifact.html：從 jsDelivr 載入 wasm 的單檔版本，可直接放任何靜態主機。
  • JSON/JSONL 改在 JS 端解析以支援離線；Parquet 需連線到 extensions.duckdb.org 下載擴充，開發環境無法測。
  • 文字檔 UTF-8 無 BOM；.ps1 含中文時用 UTF-8 BOM；.bat 純 ASCII（CRLF，由 .gitattributes 控制）。
  • 編碼稽核：node tools/audit-text.mjs（檢查 UTF-8、BOM、U+FFFD、.bat ASCII）。
  • 啟動鏈：.bat → .ps1 → node，方便分辨路徑/環境/程式問題。
  • Log 一律 JSONL，Windows 預設寫在 %ProgramData%\NewMiscCode\<專案>。
  • 建議 Node 22，以 Volta 鎖定版本；原生模組（better-sqlite3、sqlite-vec、onnxruntime）換版本後需 npm rebuild。
  • 未在 Windows 實機驗證：.bat/.ps1 啟動檔與 ProgramData 路徑只做過靜態檢查。

Three independent experiments, each with its own README.html and step-by-step verification guide:

  1. 01-mcp-ui-verifier — MCP server + CLI driving Playwright; red-box annotated screenshots and HTML reports.
  2. 02-local-semantic-search — fully local hybrid search (SQLite FTS5 + sqlite-vec + multilingual-e5-small via transformers.js, RRF).
  3. 03-duckdb-wasm-dashboard — zero-backend in-browser SQL analytics with DuckDB-WASM, log-analysis presets and charts.

All UIs support zh-TW and English. Run npm install && npm test in each folder.
