# 07 · Passkeys（WebAuthn）無密碼登入

完整說明請開啟 **[README.html](README.html)**（概覽、流程圖解、快速開始、逐步驗證、開發者指南、ASP.NET Core 對照、除錯與日誌、限制、English summary）。

- Windows：雙擊 `start.bat`（除錯模式 `start-debug.bat`，測試 `run-tests.bat`），開啟 http://localhost:3007
- Linux / macOS：`npm ci && npm start`；測試 `npm test`
- 版本：Node 22、@simplewebauthn/server 14.0.3、@simplewebauthn/browser 14.0.0（esbuild 0.28.2 本機打包）、better-sqlite3 13.0.3

English: passwordless login demo with Passkeys (WebAuthn) - Node + SQLite + SimpleWebAuthn, tested with Playwright and a CDP virtual authenticator. See README.html (English summary tab).
