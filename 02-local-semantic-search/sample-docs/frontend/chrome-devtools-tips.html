Chrome DevTools 除錯技巧

按 F12 或 Ctrl+Shift+I 開啟開發人員工具。

Network 面板

勾選 Disable cache 與 Preserve log，可以看到每個 fetch 請求的耗時、回應 JSON 與 HTTP 狀態碼。

Node.js 除錯

以 node --inspect app.js 啟動，然後在網址列輸入 chrome://inspect，點 Open dedicated DevTools for Node，即可設定中斷點。

Sources 面板

  • 條件中斷點：右鍵行號 → Add conditional breakpoint。
  • Logpoint：不改程式碼就能輸出變數。
