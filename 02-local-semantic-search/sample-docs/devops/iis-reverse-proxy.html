IIS 反向代理到 Node.js

安裝 URL Rewrite 與 Application Request Routing (ARR) 模組，並在 ARR 中啟用 Proxy。

web.config 規則

<rule name="node" stopProcessing="true">
  <match url="(.*)" />
  <action type="Rewrite" url="http://127.0.0.1:8787/{R:1}" />
</rule>

常見問題

502.3 Bad Gateway後端 Node 沒有啟動或埠號錯誤
WebSocket 斷線需在「伺服器角色」安裝 WebSocket 通訊協定
